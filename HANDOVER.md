# Handover

Everything needed to pick this project up on another machine, or hand it to
another team.

---

## What this is

An Azerbaijani-language support assistant for the Ministry of Finance
government-contracts (e-tender) portal. It answers "how do I use this system"
questions from a curated knowledge base, refuses anything outside that scope,
hands genuine requests to a human, and turns unanswered questions back into
knowledge-base entries.

Start with [`README.md`](README.md), then [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

## Two things to know before touching anything

**1. The knowledge base is invented.** All 202 entries were generated by an LLM.
They are plausible and wrong — fabricated button names, deadlines and thresholds.
Plausible-wrong is more dangerous than obviously-wrong because nobody
double-checks it.

```sql
SELECT count(*) FROM kb_entries WHERE source = 'synthetic';  -- must be 0 before go-live
```

Replacement procedure: [`docs/RUNBOOK.md`](docs/RUNBOOK.md#replacing-the-synthetic-knowledge-base).

**2. Nothing is deployed.** No TLS, no secrets manager, no backups, no retention
policy. The go-live checklist at the end of the runbook is not optional.

## Getting it running

Needs Docker, Python 3.12 (via `uv`), and a DeepSeek API key.

```bash
cp .env.example .env          # set DEEPSEEK_API_KEY
docker compose up -d          # Postgres 16 + pgvector on :5434
uv venv --python 3.12 && uv pip install -e ".[dev]"
./scripts/migrate.sh
python -u scripts/generate_seed_kb.py   # ~200 synthetic AZ Q&A (~$0.05, ~6 min)
python -u scripts/seed_db.py            # tenant + staff + KB + embeddings
uvicorn app.main:app --app-dir api --reload
```

First run downloads ~2.5GB of model weights (`bge-m3` + `bge-reranker-v2-m3`) and
takes several minutes. Later starts load from `~/.cache/huggingface` in 10–30s.

Then verify:

```bash
python -u scripts/smoke_test.py       # 59 end-to-end checks
python -u scripts/security_test.py    # 25 attacks, all must be blocked
python -u evals/run_eval.py           # retrieval quality gate
```

## What is NOT in the export

* `.env` — contains the DeepSeek API key. Copy `.env.example` and add your own.
* `data/` — generated seed content. Regenerate with `generate_seed_kb.py`.
* `.venv/`, `__pycache__/` — rebuild with `uv pip install -e ".[dev]"`.
* Model weights — downloaded on first run.
* The database — recreated by `docker compose up` + `migrate.sh` + `seed_db.py`.

**Site keys are generated per install.** Nothing hardcodes one; `/demo` reads it
from the database. Get yours from Console → Settings.

## The next three things to do

1. **Replace the synthetic content** with ministry-approved entries, and have a
   procurement expert rewrite `evals/golden_set.py`. An eval set written by the
   same model that wrote the content measures self-consistency, not correctness.
2. **Shadow mode** — run silently alongside human agents for 4–6 weeks and measure
   agreement before any citizen sees an answer. Cheapest de-risking available.
3. **Deployment** — TLS, secrets management, backups with a *tested* restore,
   monitoring. Then the pen test and WCAG audit.

## Known gaps

Listed honestly in [`docs/SECURITY.md`](docs/SECURITY.md#known-gaps) and
[`docs/ROADMAP.md`](docs/ROADMAP.md). The significant ones: no retention policy, no
TLS, no pen test, no WCAG audit, no ticketing integration, in-memory rate limiting
that assumes a single worker.

## Cost

~$0.0007 per answer (DeepSeek V3). Roughly $21/month at 1,000 answers/day.
Embedding and reranking run locally on CPU and cost nothing per query.
